# Lyriplayer（歌詞プレイヤー）

パソコンの音楽フォルダの曲を再生しながら、歌詞を歌に合わせて自動でスクロールする Windows 用の音楽プレイヤーです。

歌詞は自分で貼り付けて保存するか、曲と同じ名前の `.txt` を置くだけで表示されます。
背景には、アルバムアートをぼかして表示します。

## 主な機能

**歌詞の表示**
- 歌い出しから歌い終わりまで、歌に合わせて自動でスクロール
- フレーズ合わせ：曲を聴きながら、行ごとの歌い始めで Enter を押すと、その行がちょうどその時刻に表示位置に来る
- 区切り：歌詞の中に `---` だけの行を入れると 1 画面ぶんの空白が入り、次の歌詞が歌い出しの直前に下から上がってくる
- 歌詞の読み込み元：アプリ内に保存した歌詞 → 曲と同じ名前の `.txt` / `.lrc` → 曲ファイルに埋め込まれた歌詞

**再生と一覧**
- ライブラリ（複数のフォルダ）と自分用のリスト
- 並び替え：アルバム名・リリース年・アーティストの昇順／降順
- シャッフル（全曲／アルバム単位。アルバム単位では、すべてのアルバムを一通り再生するまで同じアルバムを選ばない）
- 前回の続きから再生

**ほかのウィンドウを使っているときの操作**
- メディアキー、Ctrl+Alt のキー、タスクバーのアイコンのボタンで操作できる
- ゲームモード：ボタンやキー 1 つで音量を決めた大きさまで下げる（キーは設定で変えられる）

**そのほか**
- 歌詞・リスト・タイミング・設定のバックアップと復元（zip）
- 設定画面からアップデート（GitHub で公開している最新版をダウンロードして入れ替え）

## 使い方

1. [Releases](https://github.com/kiring325/Lyriplayer/releases) から `Lyriplayer.exe` をダウンロードして起動します（インストールは要りません）。
2. 左上の［フォルダを追加］で、音楽の入ったフォルダを選びます。
3. 曲を選んで再生し、歌詞が無ければ［歌詞を編集］（Ctrl+E）で貼り付けて保存します。

初めて起動したときに「Windows によって PC が保護されました」と出ることがあります。
これは電子署名の無いアプリで出る表示です。「詳細情報」→「実行」で起動できます。

歌詞やリスト、設定は、各自の PC の中に保存され、外に送られることはありません（保存場所は 設定 →「データ」から開けます）。

## ソースから動かす

Python 3.10 以降が必要です。

```
pip install -r requirements.txt
python lyrics_player.py
```

## exe を作る（Windows）

```
.\build_exe.ps1 -Install
```

`-Install` を付けると、必要な部品（PySide6・mutagen・PyInstaller）も自動で入れます。
`dist\Lyriplayer.exe` ができます（フォントは exe の中に入ります）。

## 新しい版の公開（開発する人向け）

`main` に変更が入ると、GitHub Actions（`.github/workflows/release.yml`）が Windows で exe を作り、
[Releases](https://github.com/kiring325/Lyriplayer/releases) に新しい版として公開します。
版の番号は `v年.月.日.通し番号` です。アプリはこの最新版を確認して、アップデートします。

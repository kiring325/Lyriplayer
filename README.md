# Lyriplayer（歌詞プレイヤー）

パソコンに入っている音楽を再生しながら、歌詞を歌に合わせて自動でスクロールする Windows 用の音楽プレイヤーです。

- 歌詞は、貼り付けて保存するか、曲と同じ名前の `.txt` を置くだけで表示されます
- 行ごとの歌い始めを記録すると、その行がちょうど歌い出す時刻に表示位置に来ます
- 背景には、アルバムアートをぼかして表示します
- ゲーム中など、ほかのウィンドウを使っていてもキーで操作できます

## ダウンロード

[Releases](https://github.com/kiring325/Lyriplayer/releases) から、いちばん上の版の **`Lyriplayer.exe`** をダウンロードして、ダブルクリックで起動します。
インストールは要りません。好きなフォルダに置いて使ってください。

- 対応している OS：Windows 10 / 11（64 ビット）
- 初めて起動したときに「Windows によって PC が保護されました」と出ることがあります。
  電子署名の無いアプリで出る表示なので、「詳細情報」→「実行」で起動できます。

## はじめかた

1. 左上の［フォルダを追加］で、音楽の入ったフォルダを選びます（いくつでも追加できます）。
2. 一覧から曲をダブルクリックすると再生が始まります。
3. 歌詞が出ないときは、上の［歌詞を編集］（Ctrl+E）で歌詞を貼り付けて保存します。次からは自動で表示されます。

## 歌詞を表示する

次の順番で歌詞を探して表示します。

1. アプリ内に保存した歌詞（［歌詞を編集］で保存したもの）
2. 曲と同じ名前の `.txt` / `.lrc`（曲と同じフォルダ、またはその中の `lyrics` か `歌詞` フォルダ）
   - 例：`夜の駅.flac` には `夜の駅.txt`
   - `.lrc` の時刻は使わず、文字だけを表示します
3. 曲ファイルに埋め込まれた歌詞

歌詞を編集するときの便利な機能です。

- `---` だけの行を入れると、そこに 1 画面ぶんの空白が入ります（1 番と 2 番の間など）。
  次の歌詞が早く見えてしまうのを防ぎ、歌い出しの直前に下から上がってきます。
- 歌のない曲は「Instrumental」にすると、歌詞の代わりにアルバムアートだけを表示します。
- `.txt` をウィンドウにドロップすると、その曲の歌詞として取り込めます。

## 歌詞を歌に合わせる

上の［タイミング編集］（Ctrl+T）で、曲を聴きながら設定します。設定しなくても、曲の長さに合わせて流れます。

- **歌い出し・歌い終わり**：歌が始まるところで S、終わるところで E を押します。
  イントロのあいだは歌詞が下から上がってきて、歌い出しで最初の行が表示位置に来ます。
- **フレーズ合わせ**：選んでいる行を歌い始めたところで Enter を押すと、記録して次の行へ進みます。
  印を付けた行は、ちょうどその時刻に表示位置に来ます。全部の行でなくても、合わせたい行だけで大丈夫です。

手でスクロールしたときは、少しすると自動のスクロールに戻ります。歌詞の行をクリックすると、その行から再生します。

## 一覧と再生

- **自分用のリスト**：曲を右クリック →「リストに追加」で、好きな曲を集めたリストを作れます。リストの中はドラッグで並べ替えられます。
- **並び替え**：検索欄の下で、アルバム名・リリース年・アーティストの順（それぞれ昇順／降順）に並べられます。
  同じアルバムの曲は、まとめてトラック番号の順に並びます。
- **シャッフル**：全曲、またはアルバム単位で選べます。アルバム単位では、すべてのアルバムを一通り再生するまで同じアルバムは選ばれません。
- **前回の続きから**：起動したとき、前回聴いていた曲の続きから聴けます。

## ほかのウィンドウを使っているとき

- **キーボードのメディアキー**（▶⏸ ⏭ ⏮）で操作できます。
- **Ctrl+Alt+P**：再生／一時停止　**Ctrl+Alt+← →**：前の曲／次の曲　**Ctrl+Alt+M**：ミュート
- **タスクバーのアイコン** にマウスを乗せると、先頭から再生・再生／一時停止・次の曲・ゲームモードのボタンが出ます。
- **ゲームモード**：音量を、設定で決めた大きさまで下げます。下のバーのボタンか、Ctrl+Alt+G で切り替えます。
  切り替えのキーは、設定で好きなキーに変えられます。

ほかのアプリで同じキーを使いたいときは、設定でメディアキーや Ctrl+Alt のキーをオフにできます。

## キー操作（このウィンドウを使っているとき）

| キー | 操作 |
|---|---|
| Space | 再生／一時停止 |
| ← → | 5 秒戻る／進む |
| Shift+← → | 前の曲／次の曲 |
| A | 自動スクロールのオン／オフ |
| B | アルバムアートの背景のオン／オフ |
| M | ミュート |
| G | ゲームモード |
| Ctrl+F | 曲名で絞り込み |
| Ctrl+E | 歌詞を編集 |
| Ctrl+T | タイミング編集 |
| Ctrl+O | フォルダを追加 |
| Ctrl+, | 設定 |
| Delete | 選んだ曲をリストから外す（自分用のリストのとき） |

## アップデート

新しい版が出ると、起動したときに下の帯でお知らせします。
設定 →「アップデート」の［アップデートする］を押すと、最新版をダウンロードして入れ替え、自動で起動し直します。

## データの保存とバックアップ

- 歌詞・リスト・タイミング・設定は、この PC の中に保存されます。音楽フォルダにファイルを作ることはありません。
- アプリが外とやり取りするのは、新しい版があるかの確認とダウンロード（GitHub）だけです。歌詞や曲の情報を外に送ることはありません。
- 設定 →「データ」の［バックアップを書き出す…］で、全部を 1 つの zip にまとめられます。
  PC を買い替えたときなどは［バックアップから戻す…］で読み込めます（曲ファイルそのものは入りません）。

## 対応しているファイル

- 音楽：MP3 / M4A / AAC / FLAC / WAV / OGG / Opus / WMA
- 歌詞：TXT / LRC（文字だけを表示）、曲ファイルに埋め込まれた歌詞
- アルバムアート：曲ファイルに埋め込まれた画像、またはフォルダ内の `cover.jpg`・`folder.jpg` など
